## Predict, then run

Both edges are inside. `price < low` is below. `price > high` is above.

| Call | Locked result |
| --- | --- |
| `place(9n, 10n, 20n)` | `below` |
| `place(10n, 10n, 20n)` | `inside` |
| `place(20n, 10n, 20n)` | `inside` |
| `place(21n, 10n, 20n)` | `above` |

`low >= high` throws. A label of `inside` is not a fee.
